# REVO — проект №9

Двуязычный интернет-магазин кофе по макету Figma REVO. В комплекте: главная, каталог и поиск, карточки товаров с галереями и отзывами, избранное, корзина, оформление заказа, аккаунт, обращения и админ-панель.

## Запуск

```bash
npm install
npm run dev
```

## Общая база и реальные аккаунты

Проект уже умеет работать с Supabase. Без переменных окружения автоматически включается локальный демо-режим: товары, заказы и обращения сохраняются только в текущем браузере.

Чтобы все клиенты и администратор видели единые данные:

1. Создайте проект в Supabase.
2. Откройте SQL Editor и выполните `supabase/migrations/001_revo_store.sql`.
3. Скопируйте `.env.example` в `.env.local` и заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` из Project Settings → API.
4. Перезапустите `npm run dev`.
5. Зарегистрируйте аккаунт владельца и один раз назначьте ему роль командой из комментария в конце миграции.

В публичный фронтенд разрешено добавлять только anon key. Секретный service-role key нельзя помещать в `.env`, GitHub или браузерную сборку.

В подключённом режиме работают реальные сессии, защищённые роли, общий каталог, заказы и обновление данных между устройствами. Локальный тестовый доступ к демо-админке остаётся доступен через `admin@revo.coffee` с любым паролем от 6 символов.
