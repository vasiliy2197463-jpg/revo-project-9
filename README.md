# REVO — проект №9

Двуязычный интернет-магазин кофе по макету Figma REVO. В комплекте: главная, каталог и поиск, карточки товаров с галереями и отзывами, избранное, корзина, оформление заказа, аккаунт, обращения и админ-панель.

## Запуск

```bash
npm install
npm run dev
```

## Публичная база

Локальный предпросмотр сохраняет данные в браузере. Для общего каталога, реальных аккаунтов и заказов подключите Supabase: создайте проект, выполните `supabase/migrations/001_revo_store.sql`, заполните `.env` по `.env.example` и подключите SDK Supabase. Секретный service-role ключ нельзя размещать во фронтенде.

Тестовый доступ к локальной админке: войдите с email `admin@revo.coffee` и любым паролем от 6 символов.
